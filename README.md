# Backend Test Submission

This project is a backend microservice that handles URL shortening and logging.

## Structure

- `controllers/` – Business logic
- `models/` – Data models (local in-memory used)
- `routes/` – API endpoints
- `middleware/` – Custom logging middleware
- `server.js` – Main server file

## How to Run

```bash
npm install
npm run dev
